# Looper

ループ辺を、元メッシュの形状を保ったまま動かす Blender アドオン。

コーンなどにループカットを入れて `R` で回すと断面が元の面からはみ出して
形が崩れる。Looper はループの各頂点を「上下の隣接頂点を結ぶ線分（レール）」へ
射影し直して、元の形状を厳密に復元する。

## 現状（v0.3）

### Looper Rotate（モーダル / 本命）

`Alt+R`、または N パネル > Looper タブ、`Ctrl+E`、右クリックメニュー。
ドラッグ中ずっと形状が保たれたまま、頂点が既存辺の上を滑る。

ピボットはループの重心、軸は既定でビュー方向（標準の `R` と同じ感覚）。

| キー | 動作 |
|---|---|
| `X` / `Y` / `Z` | グローバル軸に拘束（同じキーで解除） |
| `Shift` | 精密モード（1/10） |
| 数値 / `Backspace` | 角度を直接入力（度） |
| `P` | モード切り替え（平面断面 / 最近点） |
| `E` | Extend Past Neighbors のトグル |
| `LMB` / `Enter` | 確定 |
| `Esc` / `RMB` | 中止（完全復元） |

### `Alt+R` が反応しないとき

NVIDIA App では `Alt+R` が「パフォーマンス オーバーレイの表示切り替え」に
既定で割り当てられている。ドライバのオーバーレイがグローバルフックでキーを
先に受け取るため、Blender までイベントが届かない。

- NVIDIA App > 設定 > **オーバーレイ** を OFF にする
  （設定 > **キーボードショートカット** から「パフォーマンス オーバーレイ」の
  キーを変更・解除するだけでもよい）
- オーバーレイの設定を変えたくない場合は、N パネル > Looper タブ、`Ctrl+E`、
  右クリックメニューから実行する

AMD の Radeon Software でも `Alt+R` が Radeon オーバーレイの既定キー。

### Fix Loop to Rails（事後補正 / 救済用）

普通に `G` / `R` / `S` で崩してしまったあと、レール上へ引き戻す。
`Ctrl+E` / 右クリックメニューから。

## 2つのモード

### Plane Section（既定）

ループ全体に最小二乗で平面をフィットし、それを傾けて、**各レールとその平面の
交点**を新しい頂点位置にする。

- 断面が必ず平面になる
- コーンなら数学的に正しい楕円断面（頂点は円錐面上に厳密に乗る）
- 指令角度と実際の傾きが 1:1（飽和しない）
- 視線方向を向いたレールの頂点もちゃんと滑る

### Nearest Point

剛体回転した理想位置から、**頂点ごとに独立して**レールへ最近点射影する。

- 元から非平面なループでも動く
- 断面は平面にならない（サドル状に歪む）
- レールの向きによって滑り量が偏り、角度を上げると効きが飽和する

通常は Plane Section。ループが元から平面でない場合や、頂点ごとの局所的な
挙動が欲しい場合に Nearest Point。

## オプション

- **Extend Past Neighbors** (default ON)
  レールを隣のループの先まで辿る。OFF にすると直近の1区間でクランプ。

## アルゴリズム

スナップショット不要。動いたのはループ頂点だけで、レールの端点（上下の
隣接ループの頂点）は動いていないため、線分は編集後のメッシュから復元できる。

1. 選択頂点 v について、非選択の隣接頂点への辺をレール候補にする
   （3本以上ある場合は最も反平行なペアを採用）
2. `extend` 時は valence 4 の頂点を辿ってエッジリング方向へ折れ線を延長
3. v を折れ線上の最近点へ射影

## テスト

```
blender --background --factory-startup --python tests/test_core.py
blender --background --factory-startup --python tests/test_modal_core.py
```

`Looper/core.py` は `bpy` に依存しないので（`bmesh` / `mathutils` のみ）
ヘッドレスでそのまま検証できる。
